# y-tooltip 1.3

**y-tooltip** is a tiny tooltip library written in **pure CSS**. No JavaScript, no dependencies, one attribute.  
Add `data-tooltip` to any element and it shows a tooltip on hover, on keyboard focus and on tap.

> 🚀 **Live page and demo:** [y-tools.dooble.us/ytooltip](https://y-tools.dooble.us/ytooltip/)

---

## ✨ Key Features

- **Pure CSS** — no JavaScript at all.
- **One attribute** — `data-tooltip="Text"`, nothing else to set up.
- **Four positions** — below (default), above, aligned left, aligned right, and combinations like top right.
- **Themeable** — colors, size, radius and width are CSS variables.
- **Accessible behavior** — appears on keyboard focus, works on touch screens, and turns animations off for `prefers-reduced-motion`.
- **Small** — about 5 KB minified.

## 📦 Installation

Download [`ytooltip.min.css`](https://y-tools.dooble.us/wp-content/themes/ytools/tools/ytooltip/ytooltip.min.css) (or the readable [`ytooltip.css`](https://y-tools.dooble.us/wp-content/themes/ytools/tools/ytooltip/ytooltip.css)) and include it in your HTML:

```html
<link rel="stylesheet" href="ytooltip.min.css" />
```

## 🚀 Usage

```html
<!-- Below the element (default) -->
<button type="button" data-tooltip="Tooltip below">Bottom</button>

<!-- Above the element -->
<button type="button" data-tooltip="Tooltip above" data-tooltip-top>Top</button>

<!-- Aligned to the left or right edge of the element -->
<button type="button" data-tooltip="Aligned left" data-tooltip-left>Left</button>
<button type="button" data-tooltip="Aligned right" data-tooltip-right>Right</button>

<!-- Combine them -->
<button type="button" data-tooltip="Above, aligned right" data-tooltip-top data-tooltip-right>Top right</button>
```

| Attribute | Description |
|---|---|
| `data-tooltip` | The tooltip text. Empty or missing means no tooltip. Default position is below the element, centered. |
| `data-tooltip-top` | Shows the tooltip above the element. |
| `data-tooltip-left` | Aligns the tooltip to the left edge of the element. |
| `data-tooltip-right` | Aligns the tooltip to the right edge of the element. Useful near the right side of the screen. |

---

## 🎨 Customization

Set the variables on one element to style a single tooltip, or on a wrapper, `:root` or `body` to style all of them.

```html
<button type="button" data-tooltip="Custom style" style="--y-tooltip-bg: #517fe5; --y-tooltip-radius: 6px;">Custom</button>
```

| Variable | Default | Description |
|---|---|---|
| `--y-tooltip-bg` | `#404040` | Background of the tooltip and its arrow. |
| `--y-tooltip-color` | `#fff` | Text color. |
| `--y-tooltip-font-size` | `16px` | Text size. |
| `--y-tooltip-font-family` | `arial` | Font of the tooltip. |
| `--y-tooltip-radius` | `15px` | Corner radius. |
| `--y-tooltip-padding` | `4px 12px` | Space inside the tooltip. |
| `--y-tooltip-max-width` | `176px` | The widest the tooltip can be before the text wraps. |
| `--y-tooltip-z-index` | `2` | Stacking order. |

## ♿ Accessibility and notes

- The tooltip is drawn with `::before` and `::after`, so it does not work on elements that cannot have them, such as `img` and `input`. Wrap those in a `span`.
- Use it on elements that can be focused, like links and buttons, so keyboard users can reach it.
- Text generated by CSS is not announced reliably by screen readers. For icon-only controls, add an `aria-label` as well.
- Elements with the class `noUiSlider` or `noUiSlider-single` are skipped on purpose.
